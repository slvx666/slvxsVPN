## 4. Что сделано (кратко, по порядку)

1. **EXE, чёрный экран.** Причина: WebView2-контроллер создавался при скрытом окне → `IsVisible=false`.
   Исправлено (`PutIsVisible` в `show()/hide()`, `WS_CLIPCHILDREN`), плюс лог этапов WebView и ошибок JS в `app.log`.
   Новая версия сама закрывает старую запущенную (у пользователя висела старая под админом).
2. **YouTube на Android медленно / с рекламой** — четыре причины, все найдены замерами с телефона по adb:
   - **tcpFastOpen** на выходах Xray — провайдер режет TCP с данными в SYN. Убран отовсюду.
   - **Большой ClientHello** (YouTube/Chrome/Go шлют постквантовый X25519MLKEM768, 2 TCP-сегмента): старые стратегии
     ByeDPI его не пробивают (поэтому и сторонний ByeByeDPI у пользователя «стал хуже»). Рабочие:
     `-s1 -q1+s -s5+s -Y` и `-s1 -q1+s -s3+s -Y` — видео googlevideo напрямую ~45 Мбит/с.
   - **Гонка при перезапуске ByeDPI** — новый процесс не занимал порт, все стратегии при подборе «падали». Исправлено.
   - **Карусель протоколов** (vless→xhttp→hy2 по кругу) — выбор теперь по доле удачных из последних 10 проверок
     (`choose()` в `engine.go`, тест `core/choose_test.go`).
   - DoH: 1.1.1.1:443 у провайдера заблокирован → 8.8.8.8 первым.
3. **Релизная сборка** (без debuggable) + диагностика в релизе: ядро копирует логи в `Android/data/app.vpn/files`.
4. **Иконка** переделана (см. выше).
5. **Код перенесён в рабочую папку** (этот репозиторий) + скрипты `tools/` для сборки/выкладки/логов.

## 5. Как работать

Всё описано в `README.md` (команды) и `CLAUDE.md` (устройство кода и грабли). Коротко:
- Правим код **здесь**; `tools/build.sh apk|apk-debug|exe <версия>` — проверка, выкладка на сервер, сборка, скачивание.
- `tools/push.sh server` — выкатить изменения подписки (`server/subserver.py`, без переустановки приложений).
- `tools/send-tg.sh <файл> "подпись"` — отправить пользователю в Telegram (только когда он просит).
- `tools/phone.sh status|logs|debug|install` — телефон пользователя по USB.
- Git-репозиторий создан, файлы добавлены, **первого коммита нет** (решает пользователь).

## 6. Что важно знать (грабли)

- **Перед любыми замерами на телефоне** — `tools/phone.sh status`: у пользователя ещё Hiddify, ByeByeDPI, Amnezia;
  adb shell ходит через активный VPN. Несколько раз из-за этого получались ложные результаты.
- Тестировать обход DPI **клиентом на Go** (большой ClientHello, как у YouTube), не curl — curl даёт ложный успех.
- Стратегии ByeDPI тестировать из adb shell **при выключенном VPN** (под `run-as` ByeDPI не принимает соединения).
- Нажатия по adb на этом телефоне заблокированы — всё, что требует тапа (включить VPN, разрешения), просит пользователь.
- speed.cloudflare.com → 429 при частых тестах; мерить на Hetzner.
- discord.com заблокирован по IP — только через VPN; это нормально.
- Пароли/токены: ключ подписи и пароль — только на сервере (`/root/build/android/vpn.keystore`, `keystore.pass`);
  `users.json`, `monitor.env`, `SUBSCRIPTIONS.txt` — только на сервере, сюда не копировать.
- Пользователь не любит, когда отчитываются «исправлено» без проверки: проверять на реальном устройстве и честно
  говорить, что проверено, а что нет.
