Состояние на 2026-09-30. Файл для продолжения работы в другом чате (без доступа к серверу).
Секреты (ключи Reality, токен бота, пароль ключа подписи APK) сюда НЕ включены — они лежат на сервере, пути указаны.

## 2. Сервер (/root/vpn)

**Протоколы (Xray-core 26.3.27, всё на 443):**
- VLESS + Reality + Vision, TCP 443 — основной (SNI www.asus.com).
- VLESS + XHTTP + Reality — запасной, fallback с 443 на 127.0.0.1:10444.
- Hysteria2 + Salamander, UDP 443 — игры/звонки; прыжки портов UDP 20000-40000 → 443 (NAT).

**Пользователи:** users.json → build.py генерирует конфиг Xray, shaper.sh (лимиты tc HTB), links.json, clash/*.yaml, SUBSCRIPTIONS.txt.
3 безлимитных (user01-03), 10 по 80 Мбит/с (user04-13). Подписка пользователя (user01, безлимит):
(ссылка — в /root/vpn/SUBSCRIPTIONS.txt на сервере)

**Службы:** xray, nginx (:8443, TLS Let's Encrypt shortlived IP-сертификат через acme.sh, автопродление), vpn-sub (subserver.py на 127.0.0.1:8081), vpn-shaper, vpn-monitor.timer (monitor.py → Telegram-бот @vpnServSup_bot, каждые 15 мин + отчёт в 12:00 МСК; токен/чат в monitor.env), vpn-app-update.timer (ежедневно 05:30).

**subserver.py** выбирает формат по User-Agent:
- `VPNApp/...` → JSON-профиль для своих приложений (сервер, ключи, сервисы, ссылки на файлы);
- clash/mihomo → YAML; браузер → страница с кнопками (в т.ч. «скачать приложение Android/Windows»); прочие → base64 ссылок;
- `/sub/<token>/file/<имя>` — файлы приложений из /root/vpn/app/files (по manifest.json).

**app_update.py:** качает гео-базы runetfreedom и урезает их (bin/geotrim) до категорий category-ru, category-gov-ru, ru-available-only-inside, youtube, twitch, discord, private, ru-blocked (только .ru); качает свежий zapret (Flowseal) для Windows; `--publish <файл> <версия>` публикует APK/EXE.

Подробный runbook — /root/vpn/README.txt (смена IP, сертификат, диагностика, zapret, игры, мониторинг).

## 3. Приложения — исходники и сборка (на сервере /root/build)

- Go 1.26.8; ядро — исходники Xray-core v26.3.27 в `/root/build/xray-src` (подключено через replace в go.mod). **В исходники Xray внесены 3 патча — при пересборке из чистых исходников их нужно повторить:**
  1. `proxy/tun/handler.go` — `recover()` в HandleConnection (паника на пакете не роняет процесс, стек в лог);
  2. `proxy/tun/udp_fullcone.go` — отправка в egress-канал под тем же замком, что и закрытие (гонка «send on closed channel»);
  3. `app/dns/fakedns/fake.go` — проверки на nil в IsIPInIPPool / GetFakeIPForDomain(3) / GetDomainFromFakeDNS (после Close() поля обнуляются).
- Модуль приложения `/root/build/app`:
  - `core/` — profile.go (формат подписки, встроенные корни ISRG), xconf.go (конфиг Xray: TUN-инбаунд, fakedns 198.18.0.0/15, маршруты), switch.go (выходы-переключатели — смена без обрыва соединений), engine.go (автовыбор протокола VLESS→XHTTP→Hy2 по TCP/UDP-пробам; сервисы напрямую/через обход с проверками и запоминанием удачного варианта для сети).
  - `bdpi/` — ByeDPI для Android (набор стратегий + фрагментация Xray).
  - `ui/index.html` — единый интерфейс (WebView) для обеих платформ.
  - `cmd/androidcore` — ядро Android (исполняемый libvpncore.so); `cmd/vpn` — Windows; `cmd/linuxtest` — стенд; `cmd/geotrim`.
- Android: `/root/build/android` — Java (MainActivity с WebView и мостом, VpnServiceImpl, Core, Bus, Prefs), ручная сборка aapt2/javac/d8/zipalign/apksigner (build-tools 35.0.1, platform 35). Ключ подписи — `/root/build/android/vpn.keystore` (пароль в памяти сервера). **Этот ключ нельзя терять**: иначе обновления не встанут поверх, придётся переустанавливать.
- Windows: `cmd/vpn` (WebView2 через jchv/go-webview2, winipcfg, wintun.dll встроен, rsrc.syso — манифест requireAdministrator + иконка).

**Маршрутизация в приложениях:**
- российские домены, category-ru и госсервисы → напрямую;
- заблокированные сайты в зоне .ru → через VPN;
- YouTube и Discord → напрямую через встроенный обход DPI (ПК: zapret/winws; Android: ByeDPI), если не работает — автоматически через VPN;
- Twitch и загрузки Steam → напрямую;
- QUIC (UDP 443) блокируется, чтобы браузер уходил на TCP;
- UDP на российские IP → напрямую; остальной UDP → Hysteria2.

## 5. Открытые вопросы / что делать дальше

1. **YouTube медленно грузит видео (~2 мин), Twitch стартует 20+ с на телефоне.** Причина — троттлинг видео, ByeDPI слабее zapret на ПК. Ждём решения пользователя:
   - **Скорость:** пустить YouTube через VPN (быстро, но с рекламой). Меняется на сервере в subserver.py → APP_SERVICES, без переустановки приложения.
   - **Без рекламы:** оставить обход и подобрать более сильные стратегии ByeDPI (bdpi.go). Нужна новая сборка и тест в реальной мобильной сети.
   - Идея, не проверенная: youtube.com (страница) через обход, googlevideo (видео) через VPN — возможно, без рекламы и быстро.
2. **Проверить Windows 1.0.2** на ПК пользователя: окно, подключение, сайты, zapret. Антивирус может ругаться на winws/WinDivert. Если не заработает — нужен скрин и app.log / xray.log.
3. «При нажатии на Подключено/пинг пинговалось заново» — не выяснено до конца. Большая кнопка — вкл/выкл; тексты — не кнопки. Нужно уточнить у пользователя.
4. Статус-бар Android: системный «ключ» VPN, текст «VPN» туда добавить нельзя (в уведомлении пишется VPN).
5. Android собирается только под arm64 (32-битные телефоны не поддерживаются).

## 6. Полезные факты и грабли

- В mihomo (Clash) Hysteria2 теряет UDP >1300 Б и 50-75% после прыжка порта; поэтому ядро приложений — Xray.
- policy.system statsInbound в Xray 26.3 НЕ включать — Hysteria2 теряет пользователя, лимиты скорости перестают работать.
- В Xray 26.3 у Hysteria-инбаунда пользователи задаются полем `clients`.
- zapret на ПК обязан работать только на реальном адаптере (--wf-iface) и исключать IP сервера (--ipset-exclude-ip), иначе ломает трафик в туннеле.
- Лаги в Apex у пользователя были из-за Wi-Fi: канал роутера и энергосбережение адаптера/USB. Решено (пустой канал + wifi-fix).
- В интерфейсе не называть JS-функции/переменные именами глобальных свойств window (top, name, status, length…) — Chromium не выполнит весь скрипт.
- Telegram: подпись к файлу — максимум 1024 символа (длинное — отдельным sendMessage); бот может слать файлы до 50 МБ.
